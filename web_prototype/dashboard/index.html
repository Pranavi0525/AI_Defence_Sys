Detection pipeline

Red Team generates traces → Blue Team scores them through four stages → fusion and policy decide the outcome.
↺ Feedback loop — misses the cascade lets through get collected, turned into hard examples, and used to retrain Stage 2. See Feedback loop below.

Cascade performance

5-fold cross-validated, out-of-fold. Each card is what that stage adds on top of the ones before it.

Risk fusion

A stacked logistic regression learns how much to trust each stage, rather than letting any one detector veto unconditionally.

Decision policy

Cost-optimal ALLOW / REVIEW / BLOCK thresholds, reweighted to an assumed production fraud rate rather than this corpus's ~19%.

Explainability

Global SHAP feature importance and a worked case, so a decision can be defended, not just reported.

Feedback loop

Not a detection stage — this is what happens after: collect what got through, generate hard examples, retrain, compare.

Run control

Triggers the real scripts as subprocesses. A full run retrains Stage 3/4 per fold — budget ~10–12 minutes.
